# Student and guardian contacts, together

**Mentora** helps coordinators of small private tuition centres in Singapore manage student records, guardian contacts and subject or class assignments in one local desktop application. It is designed for one coordinator working with approximately 30–200 secondary-school students.

[**Download Mentora from official releases**](https://github.com/AY2627S1-CS2103T-T10-4/tp/releases) · [**Get started**](UserGuide.html#getting-started) · [**Command summary**](UserGuide.html#command-summary)

## Keep everyday records organised

* **Find a student quickly.** Search by name, filter by academic level or subject, and open a profile with the student's phone and assignments.
* **Maintain shared guardian contacts.** Link siblings to one guardian and update that contact's phone once for all linked profiles.
* **Organise subjects and classes.** Create groups, assign or unassign students, and delete groups when they are no longer used.
* **Work locally with typed commands.** Records save on your computer, and built-in command help works offline.

## Start using Mentora

1. Install **Java 25** and download the JAR asset from the [releases page](https://github.com/AY2627S1-CS2103T-T10-4/tp/releases).
1. Put it in a writable folder and [launch it from a terminal](UserGuide.html#installation), using the downloaded file's exact name. Current source builds produce `mentora.jar`; older release assets may use `Mentora.jar`.
1. Follow the [first-student walkthrough](UserGuide.html#registering-your-first-student), then use the [User Guide](UserGuide.html) or type `help` in the app.

Mentora runs locally for one coordinator at a time. It does not send messages or manage attendance, grades or payments. See the [current scope and limitations](UserGuide.html#scope-and-limitations).
